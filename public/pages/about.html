About Base Quest Milestones

Base Quest Milestones combines a browser runner with on-chain run authorization and sequential ERC-721 milestone achievements on BOT Chain Testnet.

Play RunnerNFT Gallery

Goal

Make progression visible both in gameplay and in protocol-recorded NFT achievements.

Security model

Verified runs use an on-chain run session and protocol mint history instead of trusting transferable NFT ownership as the progression source.
